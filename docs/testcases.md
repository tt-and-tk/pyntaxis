# テストケース内容

`test/asm/`(`01.pt`〜`14.pt`)にある正常系テストケースを`test/test.py`で一括実行できる。call/retの多段呼び出し，P/S/F/M/IO各系命令，局所ラベルの前方/後方ジャンプ，命令数上限(`MAX_LINE_NUM`)の境界値など，`../specification/assembler.md`・`../specification/isa.md`に記載の仕様を一通り網羅する。各ファイルの内容はソース(コメント)を参照。

再帰呼び出しの形をしたテストケース(`08.pt`)も含まれるが，これは「アセンブラが呼び出しグラフを静的検査しないため機械語には変換できる」ことの確認であり，言語仕様として再帰呼び出しが動作することを意味しない(ローカル変数が固定番地に静的配置されるため，再帰呼び出しは`../specification/limitations.md`の通り非対応)。

`test/asm_err/`(`13.pt`〜`24.pt`)にある異常系テストケースを`test/test_err.py`で一括実行できる(エラーが出ることを確認する)。未定義関数・main欠如・タブ文字・引数過多・未定義ラベル・命令数上限超過等，アセンブリ言語の文法制約違反を網羅する。各ファイルの内容はソース(コメント)を参照。
